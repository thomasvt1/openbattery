# OpenBattery branding assets

New icon and wordmark generated with the built-in image-generation tool for this fork. PNG exports are resized from the generated originals, with transparent icon backgrounds preserved. The README banner has its own pale background for readability in light and dark viewers.

Icon prompt: a clean geometric app icon for OpenBattery, combining an open circular loop, an upright home-storage battery and mint lightning; deep teal with mint accent, centered square composition, no text, transparent background.

Wordmark prompt: a wide horizontal OpenBattery banner on a solid pale mint-white background, with a dark teal circular battery/lightning icon to the left and the exact text OpenBattery in a bold clean sans-serif; no extra text, texture or shadow.

`dashboard.png` is an actual Chrome capture of the local OpenBattery Home Assistant test instance. Older hardware-setup screenshots in the documentation are inherited reference material, as noted in NOTICE.md.

`phase-monitoring-mobile.png` and `site-docs/assets/phase-monitoring.png` are Chrome captures of the same isolated test instance with simulated phase currents (6.2 A import, 23 A import, 28 A export; 25 A limits). The monitoring feature was inspired by the phase-load display in [Taro's Tweakers post](https://gathering.tweakers.net/forum/list_message/86536942#86536942); these screenshots show OpenBattery's own implementation, not copied forum images.
